Página web com quatro ferramentas: calculadora de descontos, calculadora de parcelas sem juros, simulador de investimentos e divisor de despesas.

## Como executar
Abra `index.html` no navegador e clique no botão da ferramenta desejada. Os dados são solicitados por `prompt()` e os resultados aparecem em `alert()`.

## Arquivos
- `index.html` — estrutura e apresentação das quatro ferramentas.
- `style.css` — layout responsivo.
- `script.js` — lógica, validações, funções, `switch`, `for` e `do...while`.
- `ESBOCO.md` — esboço digital das interfaces previstas para a etapa 3.

## Etapas futuras
A Entrega 2 acrescentará arrays e objetos ao divisor de despesas. A Entrega 3 substituirá `prompt()` e `alert()` por formulários e resultados na própria página.
